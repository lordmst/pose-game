# 몸으로 놀기 (pose-game)

카메라 자세 인식으로 하는 아이·가족용 운동·학습 게임. 혼자 또는 둘이 동시에 대결.

- 실행: https://lordmst.github.io/pose-game/
- 이전 버전: https://lordmst.github.io/pose-game/v1/

## 게임 (13개)

| 분류 | 게임 | 시간 | 방법 |
|---|---|---|---|
| 운동 | 따라쟁이 | 40초 | 카드 그림 자세를 잠깐 유지. 빨리 하면 2배 |
| 운동 | 얼음 깨기 | 45초 | 무작위 위치에 나오는 얼음을 빠르게 쳐서 깨기. 강펀치 2타, 금색 얼음 3배 |
| 운동 | 별 따기 | 45초 | 떨어지는 별 잡기. 금별 3배, 폭탄 감점 |
| 운동 | 과일 자르기 | 45초 | 손을 빠르게 휘둘러 자르기. 연속 자르기 보너스, 폭탄 감점 |
| 운동 | 두더지 잡기 | 45초 | 튀어나온 두더지를 주먹으로. 금두더지 3배, 토끼 감점 |
| 운동 | 벽 통과 | 50초 | 다가오는 벽의 사람 모양 구멍대로 자세 잡기 |
| 운동 | 리듬 박자 | 45초 | 몸 둘레 7개 판(펌프 방식). 링이 판에 닿을 때 손 넣기. 완벽 2배, 대칭 두 판 동시 |
| 운동 | 골키퍼 | 45초 | 날아오는 공을 손으로 막기. 금색 공 3배 |
| 운동 | 달리기 경주 | 45초 | 제자리에서 무릎 번갈아 들기(무릎이 안 보이면 팔 흔들기). 10m마다 점수, 토끼보다 먼저 100m 들어오면 보너스 |
| 학습 | 수학 풍선 | 60초 | 정답 풍선을 편 손으로. 덧셈10·덧뺄20·구구단·혼합 |
| 학습 | 글자 풍선 | 60초 | 낱말 글자를 순서대로. 한글 2·3글자, 영어 3·4~5글자 |
| 학습 | 시계 만들기 | 60초 | 두 팔을 시곗바늘처럼. 정각 → 30분 → 15분 단위 |
| 학습 | 가라사대 | 60초 | "가라사대"가 붙은 지시만 따라 하기(왼쪽·오른쪽 구분 포함). 함정 지시에 가만히 있으면 점수 |

공통: 선수별 난이도(쉬움×1·보통×2·어려움×3 배점), 마지막 10초 피버(2배), 5콤보마다 보너스,
처음 하는 게임은 설명 시연, 기록·순위는 기기 브라우저에 저장.

## 파일 구조

```
index.html          화면 구성
css/style.css       디자인
js/main.js          화면 흐름, 2인 화면 분할, 점수·콤보·피버, 손으로 버튼 누르기
js/pose.js          카메라, 자세 인식(MediaPipe), 손 위치·속도 추적, 1P/2P 배정
js/audio.js         효과음·배경음악 합성, 음성 읽기
js/fx.js            파티클·점수 팝업·화면 흔들림
js/records.js       선수 목록, 기록, 순위
js/demo.js          게임 설명 시연 (만화 캐릭터가 실제 게임을 해 보임)
js/difficulty.js    난이도별 배수
js/games/*.js       게임별 규칙과 그리기 (copy, ice, star, fruit, mole, wall, rhythm, goalie, run, math, word, clock, simon)
v1/                 이전 단일 파일 버전
```

## 수정 후 배포할 때

`index.html`과 `js/` 안의 모든 `?v=숫자`를 같은 새 숫자로 올려야 브라우저가 옛 파일을 섞어 쓰지 않습니다.

## 점검용

주소 끝에 `?sim=1` 또는 `?sim=2`를 붙이면 카메라 없이 가상 선수로 동작합니다. `&op=1`을 더하면 카메라 앞 조작자도 함께 나오고(만세 안 함), `&nocheer=1`은 선수도 만세를 안 하는 상황, `&palm=1`은 왼손 편 손·오른손 주먹, `&bones=1`은 몸 뼈대 선을 보여줍니다.

# 몸으로 놀기 (pose-game)

카메라 자세 인식으로 하는 아이·가족용 운동·학습 게임. 혼자 또는 둘이 동시에 대결.

- 실행: https://lordmst.github.io/pose-game/
- 이전 버전: https://lordmst.github.io/pose-game/v1/

## 수정 후 배포할 때

`index.html`과 `js/` 안의 모든 `?v=숫자`를 같은 새 숫자로 올려야 브라우저가 옛 파일을 섞어 쓰지 않습니다.

## 점검용

주소 끝에 `?sim=1` 또는 `?sim=2`를 붙이면 카메라 없이 가상 선수로 동작합니다. `&op=1`을 더하면 카메라 앞 조작자도 함께 나오고(만세 안 함), `&nocheer=1`은 선수도 만세를 안 하는 상황, `&palm=1`은 왼손 편 손·오른손 주먹, `&bones=1`은 몸 뼈대 선을 보여줍니다. `&intruder=1|2|3`은 다른 사람이 선수 앞을 지나가는 상황(1 가까이·크게, 2 같은 거리로 지나감, 3 앞에 5초 서 있음), `&nosig=1`은 옷 색 비교를 끈 상황입니다.

`&intruder=4`는 선수와 옷 색까지 같은 사람이 선수 뒤에서 나오는 상황(얼굴로만 구분), `&noface=1`은 얼굴 확인을 끈 상황, `&kid=1`은 키 작은 아이(2인이면 1P만)입니다.

선수 인식 유지: 사람마다 윗몸통 옷 색을 기억해서, 선수가 가려진 사이 같은 거리의 다른 사람이 그 자리를 지나가도 선수로 바뀌지 않습니다. 오래 가려져도 해제하지 않고 기다렸다가, 옷 색이 맞는 사람이 다시 보이면 만세 없이 이어서 인식합니다.

얼굴 확인(보조): 만세로 선수가 잡히면 얼굴 특징값을 다섯 번 모아 기억합니다(@vladmandic/face-api, MIT, jsDelivr에서 처음 한 번 약 8MB). 평소에는 계산하지 않고, 선수가 가려졌다 다시 보일 때·찾는 중일 때·2초에 한 번 확인할 때만 계산합니다. 얼굴이 다르면 이어 붙이지 않고, 같으면 옷 색이 달라 보여도(조명) 다시 이어 붙입니다. 얼굴 정보는 기기 안에서만 계산하고 저장하지 않습니다. 그래픽 가속이 안 되거나 느린 기기에서는 자동으로 끄고 옷 색으로만 구분합니다.

키에 맞춘 높이: 얼음 깨기·두더지 잡기·골키퍼는 선수의 어깨 높이와 몸통 길이(어깨~엉덩이)를 천천히 따라가서 목표물 높이를 정합니다(js/games/bodyref.js). 2인 대결이면 선수마다 따로 맞춥니다.

자세 추가(v58): 따라쟁이·벽 통과·가라사대에 브이, 펭귄, 힘센 알통, 머리 위에 두 손, 한 손 위·한 손 옆, 한 손 위·한 손 허리, 별 자세, 다리 벌리고 허리에 손, 앉아서 만세, 무릎 들고 만세(왼·오른) 자세가 더해졌습니다(벽 통과 24가지). 벽 통과는 자세 카드를 처음부터 보여 주고, 팔다리마다 맞으면 초록·고칠 곳은 노랗게 깜빡입니다. 혼자 할 때는 자세 이름을 읽어 줍니다.

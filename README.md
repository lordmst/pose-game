# 몸으로 놀기 (pose-game)

카메라 자세 인식으로 하는 아이·가족용 운동·학습 게임. 혼자 또는 둘이 동시에 대결.

- 실행: https://lordmst.github.io/pose-game/
- 이전 버전: https://lordmst.github.io/pose-game/v1/

## 게임

| 게임 | 시간 | 방법 |
|---|---|---|
| 따라쟁이 | 40초 | 카드 그림 자세를 0.6초 유지. 2초 안에 하면 2점 |
| 수학 풍선 | 60초 | 정답 풍선을 손으로 터뜨리기. 선수별 난이도(덧셈10·덧뺄20·구구단·혼합) |
| 얼음 깨기 | 45초 | 빠르게 쳐서 깨기. 강펀치 2타, 금색 얼음 3점 |
| 별 따기 | 45초 | 떨어지는 별 잡기. 금별 3점, 폭탄 -1점 |

공통: 마지막 10초 피버 타임(점수 2배), 5콤보마다 +1, 기록·순위는 기기 브라우저에 저장.

## 파일 구조

```
index.html          화면 구성
css/style.css       디자인
js/main.js          화면 흐름, 2인 화면 분할, 점수·콤보·피버, 손으로 버튼 누르기
js/pose.js          카메라, 자세 인식(MediaPipe), 손 위치·속도 추적, 1P/2P 배정
js/audio.js         효과음·배경음악 합성, 음성 읽기
js/fx.js            파티클·점수 팝업·화면 흔들림
js/records.js       선수 목록, 기록, 순위
js/games/*.js       게임별 규칙과 그리기
v1/                 이전 단일 파일 버전
```

## 자주 바꿀 값

| 파일 | 값 | 의미 |
|---|---|---|
| js/games/ice.js | `PUNCH` (3.0) | 얼음 타격 인정 속도. 낮추면 쉽게 깨짐 |
| js/games/ice.js | `STRONG` (7.5) | 강펀치 기준 속도 |
| js/games/copy.js | `HOLD` (0.6) | 자세 유지 시간(초) |
| js/games/*.js | `sec` | 게임 시간(초) |
| js/main.js | `FEVER_SEC` (10) | 피버 타임 길이 |
| js/main.js | `UI_DWELL` (1.0) | 손으로 버튼 누르는 데 필요한 시간 |

## 점검용

주소 끝에 `?sim=1` 또는 `?sim=2`를 붙이면 카메라 없이 가상 선수로 동작합니다.
